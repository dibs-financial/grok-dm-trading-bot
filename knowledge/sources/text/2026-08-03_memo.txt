CRYPTO THEMES
Coldcard Firmware Exploit: $89-110M Drained from
~5,000 Wallets
5-year-old bug in Coldcard Mk3 firmware (2021 build) used
software RNG instead of hardware RNG — private keys
mathematically reconstructable offline. Three attack waves July
30-Aug 2: total 1,367-1,755 BTC, $89-110M, from 4,585-5,000
addresses. Patched firmware released Aug 1. Holders migrating
to new wallets (not panic selling) per Glassnode.
Bitcoin: $62,643 This Morning — Holding Despite
Hack
BTC opened $63,497, fell to $62,643. July closed at ~$63,700,
best monthly return since the current cycle began (+7%). BTC
down only ~1.7% from close despite $89-110M hack — resilience
signal. ETF AUM still >$79B. 3+ weeks of net positive flows
before this week.
CLARITY Act: 30-38% Odds, August 7 Deadline in 4

announcement by Wednesday.
September Setup + Jackson Hole Aug 27-29

Jackson Hole policy content, not just rate tone.

COLDCARD EXPLOIT SUMMARY
DETAIL
FACT
Vulnerability origin
March 2021 firmware (Coldcard Mk3, versions 4.0.1-4.1.9)
Nature of flaw
Software RNG used instead of hardware RNG for key generation
Attacker method
Reconstructed private keys offline using device serial numbers — no physical access needed
Wave 1 (Jul 30)
594 BTC, ~$38M, ~500 dormant wallets, drained in under 30 minutes
Wave 2 (Jul 31-Aug 1)
1,158 BTC, ~$75M, 2,673 addresses (Galaxy Research)
Wave 3 (Aug 2)
1,367 BTC, ~$89M, 4,585 addresses
By Aug 3 (Bloomberg)
~1,755 BTC, ~$110M, ~5,000 wallets
Fix
Patched firmware released Aug 1 by Coinkite — update immediately if affected
Affected models
Coldcard Mk3, firmware 4.0.1 through 4.1.9 (March 2021 build)
On-chain signal
Exchange reserves rose modestly; Glassnode says holders migrating to new wallets, not
panic selling
